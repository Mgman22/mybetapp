STT Betting — Match Management update

Changes:
- Kickoff time input now uses 15-minute increments (step 15 minutes: :00, :15, :30, :45).
- Body Odds and GP Odds dropdowns are grouped by Goal 1 through Goal 6.
- For each goal, options are ordered as N= then N-05 through N-100, followed by N+05 through N+100.
- Match Schedule actions are grouped into one Actions dropdown; existing Edit Match, Edit Odds, Odds History, Open/Close Betting, Suspend, Cancel, and Delete actions remain available.

No database schema or existing betting data was intentionally changed. The included betting.db is the database from the supplied project archive. Please keep a backup before testing with live data.
