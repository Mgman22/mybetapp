# Phase 3 — Bet Limits + Header polish

- Header branding now displays `STT` only and uses a single solid navy color.
- Navigation dropdowns close when a page is selected and close other groups when a new group opens.
- Bet Limits now support All Markers + All Matches, a specific marker + all matches, all markers + a specific match, and a specific marker + a specific match.
- Rule precedence: marker+match > marker-wide > all-markers+match > global.
- Existing specific bettor/match rules are migrated into the generalized rules table on startup.
- Zero means unlimited for that selection lane.
